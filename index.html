从前端开发，到 AI 应用交付 ​

React / TypeScript 开发者的学习手册 · 每天 2 小时 · 第一轮 12 周

先认识 AI 能力，亲手使用工具，再把业务问题拆清楚。通过一个完整项目，学习选择方案、实现功能并验证效果。

认识能力 → 使用工具 → 拆解业务 → 设计方案 → 接入交付 → 验证改进。

边读边练： 打开 AI 设计练习场 · Prompt / Context / Workflow / Agent 四个实验区，可使用自己的百炼或 OpenAI Key。

01先看懂能力主线分清工具与方法，理解业务拆解和四张设计卡。02认识 AI 应用全貌有哪些项目、难在哪里、企业为什么需要它们。03按 12 周路线开始每周一个目标，每个阶段留下可检查的成果。04补齐核心知识点Prompt、Context、Workflow、Agent、RAG 与 AI Coding。05让应用可靠运行权限、状态、重试、评测、费用与可观测性。06完成一个贯穿项目把需求澄清与验收助手，从业务假设做成可用产品。07按需查阅学习资源围绕当前问题学习，避免被课程和工具淹没。08记录进展与验收每周复盘、实验记录和能力自测模板。
